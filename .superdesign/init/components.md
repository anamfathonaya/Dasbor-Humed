# Shared UI Primitives

## Card Component (`.dasbor__card`)
Kontainer kartu bersudut membulat 12px, border halus 1px slate-200, padding 1.25rem, latar belakang putih / slate-800.

## Badge Component (`.dasbor__badge`)
- `.dasbor__badge--up`: Hijau lembut untuk tren positif dan status aktif / sehat.
- `.dasbor__badge--down`: Merah untuk tren negatif dan status gagal / putus.
- `.dasbor__badge--warn`: Kuning ambar untuk peringatan token kedaluwarsa atau perlu verifikasi.

## Button Component (`.dasbor__btn`)
- `.dasbor__btn`: Tombol sekunder dengan latar transparan/putih dan border slate-300.
- `.dasbor__btn--primary`: Tombol aksi primer dengan latar Sky-600 / Biru tebal dan teks putih.

## Data Table Wrapper (`.dasbor__table-wrap`)
Tabel responsif dengan border horizontal, header uppercase halus, dan sel data terstruktur rapi.
